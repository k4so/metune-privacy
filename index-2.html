MeTune

聴いた音楽を、その日の気分と一緒に。

日々の一曲を記録して、気分の移り変わりを振り返る音楽日記アプリ。友だちをフォローすれば、お互いの「今日の一曲」が見えてきます。

アプリについて

音楽の記録は、そのまま気分の記録になる。

今日の一曲を記録

曲名・アーティスト・気分・日付をまとめて保存。Apple Music の楽曲情報から素早く追加できます。

気分の移り変わりを振り返る

記録がたまるほど、季節や出来事と結びついた自分の聴き方が見えてきます。

友だちとゆるくつながる

フォローした人の記録がタイムラインに。押しつけない距離感で音楽を共有できます。

プライバシーポリシー

最終更新日：2026年8月28日

MeTune（以下「本アプリ」）は、ユーザーのプライバシーを尊重し、個人情報の適切な取り扱いに努めています。本ポリシーは、本アプリが収集する情報、その利用目的、および管理方法について説明します。

目次 1. 収集する情報 2. 情報の利用目的 3. 情報の共有 4. 利用する外部サービス 5. データの保管と削除 6. Cookie・トラッキング 7. 未成年者のプライバシー 8. ポリシーの変更 9. お問い合わせ

1. 収集する情報

本アプリは以下の情報を収集することがあります。

  • メールアドレス（アカウント登録時）
  • Apple アカウントまたは Google アカウントの認証情報
  • ニックネーム、プロフィール画像などのプロフィール情報
  • 音楽記録（曲名、アーティスト名、気分、日付など）
  • フォロー・フォロワー関係の情報
  • アプリの利用状況に関するデータ

2. 情報の利用目的

収集した情報は以下の目的で利用します。

  • アカウントの作成・管理
  • アプリの機能提供（記録の保存・表示、フォロー機能など）
  • プッシュ通知の送信
  • アプリの改善・不具合の修正
  • 利用規約違反への対応

3. 情報の共有

本アプリは、以下の場合を除き、ユーザーの個人情報を第三者に提供しません。

  • ユーザーの同意がある場合
  • 法律上の義務がある場合
  • サービス提供に必要な業務委託先（Supabase 等）への提供

4. 利用する外部サービス

本アプリは以下の外部サービスを利用しています。各サービスのプライバシーポリシーも併せてご確認ください。

Supabase データベース・認証
Apple Music API 楽曲情報の取得
Apple / Google Sign In 認証
Expo / React Native アプリ基盤

5. データの保管と削除

収集したデータは Supabase のサーバーに保管されます。アカウントを削除した場合、関連するすべての個人情報は速やかに削除されます。

6. Cookie・トラッキング

本アプリは Cookie を使用しません。また、広告目的でのトラッキングは行っていません。

7. 未成年者のプライバシー

本アプリは13歳未満の方を対象としていません。13歳未満の方の個人情報を意図的に収集することはありません。

8. プライバシーポリシーの変更

本ポリシーは必要に応じて改定されることがあります。重要な変更がある場合は、アプリ内でお知らせします。最新のポリシーは常に本ページでご確認いただけます。
